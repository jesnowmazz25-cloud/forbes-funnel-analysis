# Funnel Analysis – Data Analytics Project

## Project Overview

This project analyzes user movement through a conversion funnel to identify
where users drop off before completing a purchase.

## Objective

The main objective is to understand user drop-off at each stage of the funnel
and identify opportunities for improving conversion.

## Funnel Stages

- Visited Site
- Signup Started
- Details Filled
- Email Verified
- Purchase Completed

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Analysis

The project includes data cleaning, duplicate handling, unique user
identification, funnel stage analysis, and conversion/drop-off analysis.

## Key Findings

The analysis shows how the number of users decreases across the funnel stages
and helps identify stages where the highest user drop-off occurs.
